# XHS_ALL_IN_ONE 数据模型

> **21 张模型表**（`backend/app/models/`）+ 1 张运行时表 `app_migrations`（`database.py` 内 SQL 创建）。字段均从源码核实。

---

## 1. ER 关系图

```
users ────────────────────────────────────────────────────────
  │                                                           
  ├── platform_accounts ── account_cookie_versions（N，加密，只增不改）
  │        │                                                  
  │        ├── sub_type=pc      → 采集                         
  │        └── sub_type=creator → 发布                         
  │                                                           
  ├── login_sessions（临时，扫码/验证码登录会话）                
  │                                                           
  ├── notes ── note_assets ── note_comments                    
  │     │      note_tags（M:N）── tags                         
  │                                                           
  ├── ai_drafts ── draft_assets                               
  │     │        ai_generated_assets                          
  │     └── source_note_id → notes                            
  │                                                           
  ├── model_configs（text/image，API Key 加密）                 
  │                                                           
  ├── publish_jobs ── publish_assets                          
  │     └── source_draft_id → ai_drafts                       
  │                                                           
  ├── auto_tasks（pc_account_id + creator_account_id 双账号）  
  │                                                           
  ├── monitoring_targets ── monitoring_snapshots               
  │                                                           
  ├── keyword_groups                                          
  │                                                           
  ├── tasks（通用任务审计）                                     
  ├── notifications                                            
  └── api_logs                                                 
```

**三条主链路的表流转**：

```
采集：  notes ← note_assets / note_comments
AI：    notes → ai_drafts → draft_assets / ai_generated_assets
发布：  ai_drafts → publish_jobs → publish_assets → external_note_id
```

### 3.5 `note_assets` / `note_comments` / `tags` / `note_tags`

**note_assets**：`note_id`、`asset_type`（image/video）、`url`、`local_path`、`sort_order`（拖拽排序，`a54213910de0` 迁移加）。

**tags**：`user_id`、`name`、`color`（默认 `#111111`）。

**note_tags**：`note_id` + `tag_id` 联合主键的关联表（`Table(...)`，不是 ORM Model）。

## 5. 索引与查询模式

- **所有 `user_id` 都建索引** —— 数据隔离的查询主力（所有列表都追加 `user_id = current_user.id`）。
- `platform`、`sub_type`、`target_type`、`model_type`、`note_id`、`comment_id` 均建索引。
- 监控匹配 `_note_haystack()` 是**全表扫描**（拼接多字段转小写后 `in` 判断）——内容库变大后需关注性能。
- Cookie 取最新版本：`ORDER BY created_at DESC, id DESC LIMIT 1`。

## 6. 安全相关字段

| 字段 | 加密 | 密钥来源 |
|---|---|---|
| `account_cookie_versions.encrypted_cookies` | Fernet | `fernet_key` 或由 `secret_key` 派生 |
| `model_configs.encrypted_api_key` | Fernet | 同上 |
| `login_sessions.encrypted_temp_cookies` | Fernet | 同上 |
| `users` 密码 | PBKDF2-SHA256 26 万次 | 无需密钥 |

> ⚠️ `fernet_key` 为空时由 `secret_key` SHA-256 派生 —— **两者不分离，改 secret_key 会导致历史 Cookie/API Key 全部解不开**。生产必须显式固定 `FERNET_KEY`。
