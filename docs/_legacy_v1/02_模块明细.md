### 1.2 `xhs_utils/` — 签名算法封装

三套并列的签名状态机，结构完全对齐：

| 子包 | 用途 | 关键模块 |
|---|---|---|
| `xhs_core/` | **通用签名核心** | `auth.py`（Cookie/DS 锚点/websectiga）、`params.py`（b1、x-s/x-t/x-s-common、追踪头）、`http.py`（curl_cffi 封装）、`dsl.py`（域名/URL 常量）、`runtime.py`（**Node 桥**） |
| `xhs_pc/` | PC 端状态机 | `auth/params/http/dsl/runtime/state.py` + `js/`（aes 加解密、deflate、rap 指纹） |
| `xhs_creator/` | Creator 端状态机 | 同上结构 + `js/xhs_creator_signature.js` |

**`runtime.py` — Node 桥（核心工程约束）**：

```python
def run_node_json(argv, *, stdin_payload=None, timeout=30) -> dict
```

- 算法只存在于 `xhs_utils/**/js/`，Python 通过 `subprocess` 调 Node，**单源实现**，Python 侧不重复算法。
- 输出做**长度/前缀/正则校验**后才接受（如 b1 长度 ≥500 且为 4 的倍数、x3 必须匹配档位前缀与长度、profileData 必须是 `base64-des-ecb-zero-padding-hex` 且 10000~20000 位 hex）——这是防止算法静默降级的**护栏**。
- 失败时只保留 stderr 最后 12 行（vm 会先打印整段 JSVMP 源码）。

| 文件 | 功能 | 关键设计 |

**`scheduler_service.py` 四条 Job**：

| Job | 频率 | 作用 |
|---|---|---|
| `due_publish_runner` | `interval_seconds`（默认 60s） | 补跑到期的定时发布任务 |
| `monitoring_refresh_runner` | 同上 | 刷新监控目标快照 |

### 2.5 `adapters/xhs/` — SDK 适配层（上层唯一 SDK 入口）

| 文件 | 类 | 功能 |
|---|---|---|
| `pc_api_adapter.py` | `XhsPcApiAdapter` | 搜索/详情/评论/用户笔记，所有方法包 `direct_xhs_request_env()` |
| `creator_api_adapter.py` | `XhsCreatorApiAdapter` | 上传/发布/话题/地点/已发布作品；**图片发布核心实现**（见下） |
| `pc_login_adapter.py` | `XhsPcLoginAdapter` | PC 扫码/手机登录 |
| `creator_login_adapter.py` | `XhsCreatorLoginAdapter` | Creator 扫码/手机登录，支持 `exchange_from_user_cookies`（PC Cookie 换 Creator Cookie） |
| `request_env.py` | — | 代理环境变量隔离（`threading.RLock` 保护） |

**`creator_api_adapter._post_uploaded_image_note()` — 发布实现的关键**：

图集发布**不使用** SDK 通用 `post_note`，而是重新组装请求：

1. `get_post_note_image_data()` 组装业务体（标题/正文/图片列表/可见性）；
2. **未选地点时必须删掉 `post_loc` 键**——空对象会被服务端以参数错误打回（浏览器实抓对齐）；
3. 逐条调 `get_topic` 解析话题并拼接 `#话题名[话题]#` 到 `desc`；
4. 手动补 `x-rap-param` 头（用 PC 侧的 `generate_x_rap_param` + Creator 指纹）；
5. `upload_media` 会把 webp 自动转 JPEG（PIL，quality 92），Creator 不收 webp。

## 三、前端 `frontend/src/`

### 3.1 技术栈

React 19.2 + TypeScript 5.9 + Vite 7.3 + antd 6.3 + recharts 3.6 + react-router-dom 7.10 + axios 1.13 + zod 4.2 + @dnd-kit 6/10 + lucide-react。

**无全局状态管理库**（无 Redux/Zustand）：组件本地 state + 直接 API 调用；用 `keepalive-for-react` 做路由缓存。
