　　平台未接入 ⇒ 菜单停用（种子写入即 disabled）。接入后打开这个开关即可：菜单、权限码、工作区卡片同时出现，不改代码。
菜单启停 = 状态字段 + 保存后清受影响用户会话（与 dataPanel 的 UpdateMenu + ClearMenuUserSessions 同构）。 停用 C 行 ⇒ 该页对目标用户不可见且直链 403；停用 M 行 ⇒ 其下全部 C 行不可见，但不静默改子行状态（重启父级即恢复）。
试一下抖音这一行：打开开关 ⇒ 顶栏「抖音」工作区卡片出现（当前预览会弹提示模拟）。
实现前提是种子「只补缺不覆盖」：用户手工启用的菜单，升级时不会被 menus.seed.json 打回 disabled。
