> **状态**：调研中（2026-10-26）。**本文档只记录调研过程与结论，不代表已实施。**
> **需求来源**：用户 2026-10-26 口径（四条）——

## 2. 真机验证记录（账号 8「观隅好物的店」）

> 验证方式：Chrome CDP（127.0.0.1:9222）+ 页面 XHR/fetch 拦截 + CDP Network.requestWillBeSent。
> ⚠️ **方法论教训**：页面内 JS 钩子对 SPA 跳转/新标签页必然失效，必须在页面打开**之前**订阅网络层事件；
> 本次「保存草稿」抓到 0 个业务请求，正是靠「网络层 0 请求」这一阴性证据坐实了「无服务端接口」。

### V1 · 千帆笔记草稿箱无服务端 API ✅ 已确认

| 项 | 结论 | 证据 |
|---|---|---|
| 点创作页「保存草稿」是否打平台接口 | ❌ **零业务请求** | 装 XHR/fetch 拦截 + CDP Network 双通道，持续 18 秒只捕获 7 个遥测请求（`apm-fe` / `spider-tracker`），`ark.xiaohongshu.com/api/*` **0 条** |
| 草稿页面自带说明 | 原文已抄录 | 「草稿存储于当前使用的浏览器本地，在清除浏览器数据时会被删除；最多支持保存20篇草稿，超出后将默认自动删除最后一篇草稿，请及时发布。」 |

### V7 · 草稿 `images[]` 的真实结构 ✅ 已确认

**验证方法**：创作页（`/app-note/publisher`）通过 CDP `DOM.setFileInputFiles` 上传一张 1080×1440 PNG → 填标题 → 点「保存草稿」→ 读 `initiative_drafts`。

**实测结果**：
```jsonc
{
  "file": {},                 // 空对象，不是文件本体
  "status": 2,                // 2 = 上传完成
  "url": "blob:https://ark.xiaohongshu.com/<uuid>",   // 本地预览 blob，不可持久化
  "key": "u2_test_image.png17930167652401793017126026", // 本地生成，非平台字段
  "progress": 1,              // 1 = 100%
  "fileId": "spectrum/2z9mLRfEBaewiRmX8g97YAgFPD2vWx3B3vN8UuyPngHigEk"  // ★ 唯一需要持久化的字段
}
```

**关键结论**：
1. **`fileId` 是唯一真值**，格式 `spectrum/<id>`，与项目现有上传链路 `upload_web_permit(biz_name="spectrum", scene="image")` 的返回一致 ⇒ **图片可复用现有上传逻辑，无需新增**。
2. `url` 是 `blob:` 本地预览地址，**写入时必须由页面自己生成**，不能写死；写入方只需提供 `fileId`。
3. `coverContext.coverUrl` 为空（未单独设置封面时）。
4. `images` 数组元素**不需要** width/height/mime，只要 `fileId` + `status: 2` + `progress: 1` 即可被草稿箱识别。

**创作页可用控件**（同轮扫出）：
- 图片 file input：`accept=".jpg,.jpeg,.png,.webp"`，`multiple=true`
- 视频 file input：`accept=".mp4,.mov,.flv,.f4v,.mkv,.rm,.rmvb,.m4v,.mpg,.mpeg,.ts"`，`multiple=false`
- 按钮：`添加商品 / 扫码上传 / 素材库 / 保存草稿 / 发布笔记`

### V9 · 生产环境（内置 Electron 内核）可开 CDP ✅ 已确认

**验证方法**：用安装目录下的真实内核 exe 加 `--remote-debugging-port` 启动，再用 HTTP 探测 CDP。

```
exe: .hermes/deps/window-host/SpiderXHSWindow.exe   (188,614,144 bytes)
cmd: SpiderXHSWindow.exe --url=http://127.0.0.1:8000 --profile=<dir> --remote-debugging-port=9333

结果：
  GET http://127.0.0.1:9333/json/version → {"Browser": "Chrome/130.0.6723.118"}
  GET http://127.0.0.1:9333/json        → [{"title":"Spider_XHS Operations","url":"http://127.0.0.1:8000/login"}]
```

**关键结论**：
- 内置窗口内核是 **Electron 30.x**（`packaging/window-host/main.js`，Chromium 130），**原生支持** `--remote-debugging-port`。
- 启动器 `packaging/launcher.py::open_app_window()` 已有 `--url=` / `--profile=` 两个参数，**只需追加一个 `--remote-debugging-port=<n>`** 即可开启 CDP。
- 因此 CDP 写 IndexedDB 在**装包版同样可行**，不是只有调试 Chrome 才行。

⚠️ 副作用：开启调试端口意味着本机任意进程可操控该窗口。需绑定 `127.0.0.1` 且端口随机/校验，不能暴露到局域网。

### V13 · 20 篇上限不会自动淘汰 ✅ 已确认（推翻页面文案）

**验证方法**：写入 22 条 `createTime` 递增的测试草稿（原有 1 条 ⇒ 共 23 条），刷新草稿箱页观察。

**结果**：
- 页面**显示全部 22 条**测试草稿（无截断）
- IndexedDB 仍是 **23 条**，无任何删除
- 清理时删除 22 条，余 1 条，页面复核无残留

**结论**：「最多保存 20 篇，超出后自动删除」是**前端写入路径的限制**，**直接写 IndexedDB 会绕过它**。
⇒ 我方批量写入时必须**自己在写入端做上限控制**（建议每次写入前先查条数，超限则先删最旧）。

### V14 · 草稿编辑走 sessionStorage `draftId` 指针 ✅ 已确认

**验证方法**：写一条带标题/正文的草稿 → 刷新草稿箱页 → 点该行「编辑」→ 读新页的 sessionStorage。

**结果**：点「编辑」后新开标签页，URL 为
```
/app-note/publisher?sessionId=48b2486c-2a45-494e-8717-fafaae1d0b59&source=noteCreation-DraftEdit
```
sessionStorage 中**由页面自己写入**：
```json
{
  "version": 1,
  "createdAt": 1793017534578,
  "context": {
    "source": "noteCreation-DraftEdit",
    "draftId": "image_1793017482387_u7test"     // ★ 指向 IndexedDB 里的草稿
  }
}
```

**结论**：
1. 回填链路 = `sessionStorage["note-publish-v2:<sessionId>"].context.draftId` → 页面自己去 IndexedDB 读
2. **写入方不需要手动写 sessionStorage** —— 点「编辑」时页面会自己写
3. 因此「只写 `initiative_drafts`」在链路设计上是完备的

⚠️ **未闭环的点**：实测直接导航或点编辑后，该 publisher 页**微前端未挂载**（`#single-spa-ark-app-note` innerHTML 有 80 万字符但 `innerText` 为 0，且 0 异常 / 0 网络失败 / 0 API 请求）。这更像「页面加载时序 / 微前端挂载问题」而非草稿数据问题，**`draftId` 能被正确读到这一环已证明，后续渲染未验证**（见 U7b）。

### CDP 抓包方法论沉淀（血泪教训）

| 教训 | 说明 |
|---|---|
| **页面内 JS 钩子对 SPA 跳转/新标签页必失效** | 本次「保存草稿」在创作页装 XHR/fetch 拦截，点击后自动跳到 `creation?drafts` 页，钩子随旧页面销毁 |
| **阴性证据同样有力** | 双通道（页面钩子 + CDP Network）同时 0 命中 ⇒ 坐实「无服务端接口」 |
| **直连页级 ws 最稳** | `http://127.0.0.1:9222/json` 取 `webSocketDebuggerUrl` 直接连，同步 `await ws.recv()` 逐条读；`Target.attachToTarget` + 异步读循环在本机实测会挂死 |
| **空白新标签页无法 evaluate** | `Target.createTarget` 出来的空白页 `Runtime.evaluate` 恒返回 `null`，必须复用已有业务页或等页面自己加载 |
| **受控输入必须用原生 setter** | React 受控组件直接改 `el.value` 不触发 onChange，必须 `Object.getOwnPropertyDescriptor(HTMLInputElement.prototype,'value').set.call(el, v)` + `dispatchEvent(new Event('input',{bubbles:true}))` |
| **文件上传走 `DOM.setFileInputFiles`** | 绕过系统文件选择框；需先 `DOM.getDocument` 拿 rootId，再 `DOM.querySelector` 拿 nodeId |
