## 一、发货模式 → **字段按模式变化**（用户明确要求调研的点）

真机逐个切换（读回 diff），**四种模式只有两套字段**：

| 发货模式 | 出现的时间字段 | 具体控件 |
|---|---|---|
| **现货模式** | `现货发货时间` | 三选一按钮：`当日发货` / `24小时` / `48小时`（带「推荐」角标） |
| **全款预售模式** | `全款预售发货时间` | 两选一：`时段预售` / `定时预售` |
| **现货+预售模式** | **与全款预售完全相同** | 同上 |
| **按规格设置发货时间** | **与全款预售完全相同** | 同上 |

⚠️ **纠正**：`现货+预售模式` 与 `按规格设置发货时间` 并非「没抓到」，而是**字段与全款预售一致** ——

## 十一、实现口径

1. **发货模式是联动字段**：四模式**四种不同**参数变化（见 §六），切换要**二次确认**。
2. **物流模板未选** → 发货模式/时间**禁用** + 提示「请先选择物流模板」。
3. **物流模板 / 运费模板走下拉**，候选来自 `getSellerCarriageTemplate`，默认选 `defaultShippingTemplate`；**不做新建**。
4. **规格类型 = 复选框一行**（上限 2，候选来自平台 `saleProperties`）；**规格值 = 一框一值**（回车追加空框）。
5. **发货模式变化的那段参数用虚线框**包住 + `margin-left: 126px`（不顶头）。
6. **预售发货时间默认展开**（不用先点「展开」）。
7. **布局按真机几何**：**左右两栏**（左「商品发布助手/发布提示」200px、右参数配置）+ 字段标签列 **126px**（左对齐）+ 行 gap **4px** + 分区标题 14px/字重 400 + 属性区**三列栅格**（列距 332px）。
8. **商品属性标题始终展示**（无值也显示 + 一行说明，不造假）。
9. **「商品发布助手」只保留「字段 + 错误原因」两列**，超长走 Tooltip；不展示分区列与「去填写」按钮。
10. **分区锚点 6 个**（含「尺码信息」「商品资质」）。
11. **尺码信息**（按类目激活）：三类表 **基础尺码 / 尺码推荐 / 模特试穿**（bundle 另有「商品尺寸 / 新尺码推荐」），每类两种配置方式 —— **表格填写 / 上传图片**（`sizeTableConfigType = FORM | IMAGE | UN_SET`）。
    - **基础 / 模特表** state：`argList` + `customArgList` + `selectedArgIds` + `sizeData`
    - **推荐表**多一维：`normalSizeData` + `complexSizeData`（行列二维，键 = `genId.complexSizeData(rowId, colId)`）
    - 建议文案：`经数据验证补充尺码表可有效提升商品转化，建议补充准确的尺码信息`
    - ⚠️ 具体表单**不做**：当前类目（住宅家具>桌类）不激活该区，无真机数据可对，做出来是猜的。
12. **组合品**（真机 `isUnionGood`，入口 = URL `?goodType=union`，**同页面不同模式**）：
    - 一个商品 = **成员商品** 列表（`memberItems`，**最少 2 最多 5**），每个成员带 `subSkuDetails`（SKU 明细）
    - 校验原文：`请输入组合品名称` / `组合品名称长度不能超过 N 个字符` / `组合品名称不能与「X」的组合品名称一致` / `请输入组合品售价` / `组合品售价不能小于 N 元` / `组合品售价不能大于参考原价(X元)` / `请至少选择 N 个成员商品` / `最多设置 N 个成员商品` / `成员商品的库存类型需要一致`
    - 判据三分：`isSingleGood`（单品走 `skuList`）/ `isUnionGood`（组合品走 `memberItems`）/ `isChannel`（渠道品）
    - ⚠️ **范围外：本项目只做单品发布，组合品整条链路不做**（用户口径 2026-10-09）。上面这些只是调研记录，供将来若要扩展时参考；页面里**不实现**组合品分支。

### 13.1 关键发现：**16 个加载型 action 只依赖 `categoryId`**

| `getRecommendTrendingWords` | 推荐热搜词（短标题/标题用） |
| `checkNeedBrand` | 该叶子类目**是否必须填品牌** |
| `searchMarketableBrands` | 可选品牌候选 |
| `getShortTitleRuleConfig` | **导购短标题规则**（自动生成的依据） |
