# 62 · 功能设计 · 平台工作区隔离与动态工作区选择页

> 用户口径（2026-10-25）：
> ① 「系统管理单独新增一个平台工作区，不是在小红书平台内新增菜单」
> ② 「小红书平台内应只有小红书平台自己的相关内容」「各个平台是隔离的，不要混乱在一起」
> ③ 「个人资料应在头像下拉中展示」
> ④ 「选择平台工作区属于顶级菜单，用户存在什么菜单就展示什么，动态控制」

# 一、现状与根因

数据层**早已支持隔离**：菜单 M 行带 `workspace`（xhs/ai/system/douyin…），
`GET /system/menus/mine` 已有 `workspace` 过滤参数（含祖先保链），前端 `fetchMyMenus`
也已有 workspace 形参。**断点全在消费侧**：

| 断点 | 后果 |
|---|---|
| `AppShell` 不区分工作区，`fetchMyMenus()` 不传 workspace | 小红书侧栏把 系统管理/大模型网关/个人资料 全部混进来 |
| 工作区选择页卡片**前端写死** | 新工作区要改代码发版；无权限用户也看得到卡片 |
| 个人资料是侧栏 C 行 | 与「头像下拉」的用户惯例冲突 |

# 二、方案（四件事）

## 2.1 侧栏按工作区过滤（平台隔离）

`AppShell` 从路由派生当前 workspace（`/system/*`→system；`/platforms/:id/*`→id；
`/tasks` `/task-records` `/models` `/settings` `/403`→xhs），传给 `useDynamicNav(workspace)`
→ `fetchMyMenus(workspace)` → 后端只回该片 + 公通行。**profile 行 workspace 改 `common`**
（perms_registry 改值 → 重新生成种子 → 迁移 UPDATE 存量行；播种「只补缺不覆盖」不会改它），
从此不进任何工作区侧栏 —— 个人资料改由头像下拉直达 `/profile`。

公共行语义：`workspace in ('', 'common')` 的行不属任何平台，**不随工作区过滤出现**。

## 2.2 工作区选择页动态化（顶级菜单）

新端点 `GET /api/system/menus/workspaces`（登录即可，无权限码）：从 `_visible_menus_for`
+ 全量 M 行（含 disabled）产出卡片清单：

```json
{"items": [{"workspace": "xhs", "name": "小红书", "icon": "xiaohongshu",
            "status": "normal", "enterable": true}, ...]}
```

* 卡片 = 顶级 M 行（`is_visible=true`）；`status=normal` 且用户在该片有 ≥1 条授权可见行
  → `enterable=true`（Active / 公共）；`status=disabled` → Coming Soon（预留入口照旧）；
  normal 但用户**无任何授权** → 不出现（动态控制的落点）。
* 前端徽标：`workspace in {ai, system}` → 公共；`enterable` → Active；`disabled` → Coming Soon。

## 2.3 头像下拉

`workspace-shell` 右上 Avatar 加 Dropdown：**个人资料**（→ /profile）+ **退出登录**；
左下角既有用户条不变。`/profile` 路由移出 AppShell，改独立全屏页（同 `/llm-gateway`
壳模式，带返回工作区入口）。

## 2.4 系统管理工作区路由

卡片 → `/platforms/system`（`ComingSoonPage` 兜底路由改为按工作区分发：`system` →
AppShell 布局 + `/system/users` 重定向；其余未知平台仍 ComingSoon）。AppShell 在
system 工作区取 workspace=system 菜单片，侧栏只剩系统管理自己的组。

# 三、验收

1. xhs 工作区侧栏只出现 workspace=xhs 的组 + footer 工具；系统管理/大模型网关/个人资料不出现。
2. `/platforms/system` 侧栏只有系统管理组；工作区页有「系统管理·公共」卡片。
3. 工作区页卡片 = 后端下发（无权限的工作区不出现；disabled 显示 Coming Soon）。
4. 头像下拉有 个人资料/退出登录；`/profile` 独立页可用；侧栏无个人资料。
5. 守卫联动：`test_sidebar_business_lines` 计数随侧栏结构回数；种子行数不变（180）；
   权限码↔菜单行对账不变（profile 行还在，只是换了 workspace）。
