# 三、三份新文档的规格

## 3.1 55 · 接口文档（系统管理域 + 认证域 + 权限中间件）

**内容结构**（每个端点一条）：

| 字段 | 说明 |
|---|---|
| 方法与路径 | `POST /api/system/users` |
| 权限码 | `system:user:create` |
| 请求体 | 逐字段：名称 / 类型 / 必填 / 约束 / 示例 |
| 响应体 | 逐字段 + 示例 JSON |
| 错误码 | 完整清单：HTTP 码 + `detail.code` + 触发条件 |
| 副作用 | 改了哪些表 / 是否 `token_version+1` / 是否清缓存 |
| 幂等性 | 重复调用会怎样 |

**覆盖范围**：`+41` 个端点逐条 + 权限中间件的统一错误契约 + `/auth/me` 的新响应形状。

## 3.2 56 · 前端接口层契约

| 内容 | 说明 |
|---|---|
| `lib/api.ts` 新增请求函数 | 41 个函数名 + 签名 + 返回类型 |
| `types/index.ts` 新增类型 | User / Role / Menu / DictType / DictItem / Workspace / PermissionSet |
| 错误处理约定 | `detail.code` 如何映射到 UI（表单字段级 vs 全局 message） |
| `usePermission` / `useDict` 契约 | 入参 / 返回 / 缓存语义 |
| 路由守卫契约 | `RequirePerm` / `RequireWorkspace` 的行为 |

## 3.3 57 · 施工顺序与验收矩阵
