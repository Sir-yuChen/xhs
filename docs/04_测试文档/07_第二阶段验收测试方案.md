## 2. 方向 1 · 大模型生成 + 素材库 + 提示词模板

**验收标准（DoD）**
- [ ] LLM 供应商可增删改、可设默认，连通性测试可回真实结果，**密钥脱敏**（列表/日志不现明文）。
- [ ] 商品 → 笔记：标题（≤20 字多备选）+ 正文（600–900 字）+ 话题标签（平台形态 `#话题[话题]#`）+ 封面文案。
- [ ] 媒体生成：文生图 / 图生视频 / 图文拼图，**图 ≤6、视频 ≤1**（视频优先），带 AIGC 溯源 `aigcTaskId`。
- [ ] 本地素材库：多文件夹增删、扫描索引、按文件夹分组、搜索、选用；大文件夹分页 + 增量。
- [ ] 提示词模板：公共模块 + 单独模板，可组合渲染最终 Prompt。
- [ ] 笔记媒体可复用商品原始详情图 / 参考原始图生成新图，生成图可落素材库 + 用于当前笔记。
- [ ] **生成绝不自动发布**。

## 6. 方向 5 · 自动化工作流

**验收标准（DoD）**
- [ ] 工作流编排：触发器→生成→审核→定时→发布→监控 节点链，参数可配。
- [ ] 一键执行：多商品→多笔记→审核（人工）→定时→多账号发布。
- [ ] 步骤日志 + 失败重试（幂等）+ 复盘回填仪表盘。
- [ ] **审核节点默认人工，发布不自动放行**；发货/售后**不进工作流**。
- [ ] **不新造底座**：执行下沉一期 `tasks` 队列；账号互斥/批次号/快照/孤儿清理/调度装配全部复用；
      `notes` 表**零加列**（排期走独立表，方案 A）；无新建线程池。

**关键测试用例**

## 7. 方向 6 · 订单模块（两期，重点）

### 7.1 一期只读 · 验收标准（DoD）
- [ ] 订单同步：取 ark 令牌 → 分页**增量**拉取 → 按 `order_no` **幂等 upsert** → 状态映射 → 落库 → 回写 `synced_at`。
- [ ] 订单查看：列表/详情/筛选（状态/时间/关键词）/搜索/导出。
- [ ] 订单监控：订单量/GMV/客单价/转化率/退款率/发货时效/来源归因，接入仪表盘。
- [ ] 越权订单返回空集（不 404）；无 ark 令牌 400 结构化原因，**不借会话**。
- [ ] 界面默认**脱敏展示**（手机/姓名/地址），完整值仅发货/打单/导出使用。

### 7.2 一期只读 · 关键测试用例

### 7.3 二期写操作 · 验收标准（DoD）
- [ ] 发货：前置校验（本店∧待发货）→ 填物流+单号 → **二次确认** → 调千帆接口 → 成功落物流+状态流转 / 失败记原文可重试。
- [ ] 售后：校验（待处理）→ 同意/拒绝+理由 → **二次确认** → 状态流转。
- [ ] **绝不自动发货/退款**；发货/售后不进工作流；批量发货逐条回滚、回执区分部分成功。
